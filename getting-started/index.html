Running the games

The games are combined in a single KivyMD app, MDClassics, in the source/MDclassic_games folder. It uses uv with Python 3.11. The root pyproject.toml and uv.lock are the authoritative dependency definitions; a runtime requirements.txt is generated from the lockfile (excluding development and Android host tooling).

If Kivy's native dependencies are not already available on your system, follow the Kivy installation instructions for your platform first.

Installing and running

With uv

From the repository root, create the locked environment:

# Working directory: repository root
uv sync --locked

Then change into the app folder before running, because the app loads its KV files and assets through relative paths:

# Working directory: source/MDclassic_games
uv run --locked python main.py

With pip

From the repository root, create a Python 3.11 virtual environment and install the generated requirements:

# Working directory: repository root
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

Then change into the app folder before running:

# Working directory: source/MDclassic_games
python main.py

Observed status: desktop compatibility and acceptance passed with Kivy 2.3.1 and KivyMD 2.0.0, with the common Pillow 11.3.0 / pycairo 1.28.0 supporting pins. See the validation record for full details.

Android

Android is a developer-only topic. Setting up the Android toolchain, building the APK and installing it on a device are documented in the repository's development guide.

Ready-to-install APKs for published versions are kept in the releases folder of the repository.
