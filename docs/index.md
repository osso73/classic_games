# Classic games

A series of classic games built with [Kivy](https://kivy.org/) and
[KivyMD](https://kivymd.readthedocs.io), combined into a single app, **MDClassics**,
with seven games:

- [Pong](games/classic_games.md#game-of-pong)
- [Ahorcado (hangman)](games/classic_games.md#game-of-ahorcado-hanged)
- [Memory](games/classic_games.md#game-of-memory)
- [15 puzzle](games/classic_games.md#game-of-15-puzzle)
- [2048](games/classic_games.md#game-of-2048)
- [Buscaminas (minesweeper)](games/classic_games.md#game-of-buscaminas-minesweeper)
- [Snake](games/classic_games.md#game-of-snake)

How to play each game, its controls and its settings are documented in the
[combined app help](games/classic_games.md). To install and run the app on your
computer, see [Getting started](getting-started.md).
